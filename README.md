Simulación de un Sistema Operativo Básico

Descripción:
Este proyecto consiste en una simulación sencilla de un sistema operativo desarrollada en Python. El programa permite gestionar procesos, mostrar estados, ejecutar algoritmos de planificación y simular operaciones de entrada/salida mediante una interfaz tipo terminal.

El objetivo principal es aplicar conceptos fundamentales de sistemas operativos vistos en clase.

- Características del sistema
- Gestión de procesos

El sistema permite:
- Crear procesos
- Mostrar procesos registrados
- Eliminar procesos mediante PID
- Estados de procesos

Cada proceso puede encontrarse en alguno de los siguientes estados:
- Listo
- Ejecutando
- Bloqueado
- Terminado
- Algoritmos de planificación implementados
- FCFS (First Come First Served)

Los procesos se ejecutan en el orden en el que fueron creados.
- Round Robin
Los procesos se ejecutan utilizando un quantum de tiempo definido por el usuario.
- Simulación de Entrada/Salida (I/O)

El sistema simula bloqueos de procesos por operaciones de entrada/salida utilizando eventos aleatorios.
